# StarSim Core 0.9.0-beta.1 — First Public Beta

Release date: 2026-09-21  
Platform: Windows x64  
Official website: [https://starsim.ro/](https://starsim.ro/)

## Română

### Despre această versiune

`0.9.0-beta.1` este prima versiune beta publică StarSim Core. Aplicația este destinată postprocesării matematice, nedistructive, a imaginilor astronomice deja stivuite. Nu efectuează stacking, nu procesează fișiere video și nu generează detalii cu inteligență artificială.

Aceasta este o versiune beta: păstrați întotdeauna imaginea sursă și exportați rezultatul într-un fișier nou.

### Fișierele release-ului

- `StarSimCore-Setup-0.9.0-beta.1-win-x64.exe` — installerul recomandat;
- `StarSimCore-0.9.0-beta.1-win-x64-portable.zip` — versiunea portabilă;
- `SHA256SUMS.txt` — amprentele SHA-256 pentru verificarea fișierelor;
- `StarSimCore-Setup-0.9.0-beta.1-win-x64-README.md` — acest document.

Descărcați build-uri numai din pagina Releases a repository-ului oficial sau din linkurile publicate pe [starsim.ro](https://starsim.ro/).

### Cerințe

- Windows 11 x64 — platforma recomandată și suportată;
- Windows 10 22H2 x64 — compatibilitate beta, best effort;
- procesor x64;
- drepturi de administrator pentru instalare;
- spațiu liber pentru aplicație și imaginile procesate.

.NET 10 și Microsoft Visual C++ Runtime sunt incluse sau instalate de pachet; utilizatorul nu trebuie să instaleze separat SDK-ul .NET.

Windows ARM64, Windows 7 și Windows 8.1 nu sunt suportate în această versiune.

### Instalare

1. Descărcați installerul și `SHA256SUMS.txt` din aceeași versiune GitHub Release.
2. Verificați amprenta SHA-256 dacă fișierul a fost descărcat din altă locație decât linkul oficial.
3. Porniți `StarSimCore-Setup-0.9.0-beta.1-win-x64.exe`.
4. Alegeți română sau engleză.
5. Opțional, creați scurtătura pe desktop.
6. Finalizați instalarea și porniți StarSim Core.

Installerul beta poate afișa o avertizare Microsoft Defender SmartScreen până când distribuția beneficiază de semnare digitală și reputație. Verificați întotdeauna sursa și SHA-256 înainte de a continua.

### Ce include

- flux Beginner cu ținte și presetări planetare;
- mod Expert cu procesori independenți;
- motor Wavelet în 6 straturi cu controale Classic și Advanced;
- diagnostic Wavelet și export pe straturi;
- reducere de zgomot, deconvoluție, contrast local și accentuare;
- aliniere RGB, culoare, saturație, expunere, contrast și gamma;
- comparație Original/Procesat;
- Undo/Redo, proiecte `.starsim`, presetări personalizate și export;
- interfață și ajutor în română și engleză;
- Plugin Manager, plugin demonstrativ și SDK C++ pentru pluginuri;
- installer și versiune portabilă Windows x64.

### Limitări cunoscute ale beta-ului

- Windows 10 este oferit numai best effort și trebuie verificat pe configurația utilizatorului;
- nu există actualizare automată;
- performanța depinde de dimensiunea imaginii, procesor și memoria disponibilă;
- pluginurile native rulează în proces și trebuie instalate numai din surse de încredere;
- build-urile modificate și fork-urile nu sunt build-uri oficiale StarSim Core.

### Raportarea problemelor

La raportarea unei probleme, includeți versiunea StarSim Core, versiunea Windows, pașii de reproducere și, dacă este relevant, logul aplicației după eliminarea căilor sau datelor personale. Pentru probleme de securitate urmați `SECURITY.md` și nu publicați imediat detaliile exploatabile.

## English

### About this release

`0.9.0-beta.1` is the first public StarSim Core beta. It provides non-destructive mathematical post-processing for already-stacked astronomical images. It does not stack frames, process video files, or generate image detail using artificial intelligence.

This is beta software. Always preserve the source image and export processing results to a new file.

### Release files

- `StarSimCore-Setup-0.9.0-beta.1-win-x64.exe` — recommended installer;
- `StarSimCore-0.9.0-beta.1-win-x64-portable.zip` — portable package;
- `SHA256SUMS.txt` — SHA-256 checksums;
- `StarSimCore-Setup-0.9.0-beta.1-win-x64-README.md` — this document.

Download builds only from the official repository Releases page or from links published on [starsim.ro](https://starsim.ro/).

### Requirements

- Windows 11 x64 — recommended and supported platform;
- Windows 10 22H2 x64 — best-effort beta compatibility;
- x64 processor;
- administrator privileges for installation;
- free space for the application and processed images.

.NET 10 and the Microsoft Visual C++ Runtime are bundled or installed by the package. End users do not need the .NET SDK.

Windows ARM64, Windows 7 and Windows 8.1 are not supported by this release.

### Installation

1. Download the installer and `SHA256SUMS.txt` from the same GitHub Release.
2. Verify the SHA-256 checksum if the file came from anywhere other than the official link.
3. Run `StarSimCore-Setup-0.9.0-beta.1-win-x64.exe`.
4. Select Romanian or English.
5. Optionally create a desktop shortcut.
6. Complete installation and launch StarSim Core.

Microsoft Defender SmartScreen may warn about this beta installer until the distribution gains digital signing and reputation. Always verify the source and SHA-256 checksum before continuing.

### Included features

- Beginner workflow with planetary targets and presets;
- independent Expert processors;
- six-layer Wavelet engine with Classic and Advanced controls;
- Wavelet diagnostics and per-band export;
- noise reduction, deconvolution, local contrast and sharpening;
- RGB alignment, color, saturation, exposure, contrast and gamma;
- Original/Processed comparison;
- Undo/Redo, `.starsim` projects, custom presets and export;
- Romanian and English interface and help;
- Plugin Manager, demonstration plugin and C++ Plugin SDK;
- Windows x64 installer and portable package.

### Known beta limitations

- Windows 10 support is best effort and must be confirmed on the user's system;
- there is no automatic updater;
- performance depends on image size, CPU and available memory;
- native plugins execute in-process and must be installed only from trusted sources;
- modified builds and forks are not official StarSim Core builds.

### Reporting problems

Include the StarSim Core version, Windows version, reproduction steps and relevant logs with personal paths or data removed. Follow `SECURITY.md` for security reports and do not immediately publish exploitable details.
