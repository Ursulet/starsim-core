# StarSim Core 1.0.0 — First Stable Release

Release date: 2026-09-23  
Platform: Windows x64  
Official website: [https://starsim.ro/](https://starsim.ro/)

## Română

### Despre această versiune

StarSim Core `1.0.0` este prima versiune stabilă a aplicației pentru postprocesarea matematică și nedistructivă a imaginilor astronomice deja stivuite. Versiunea păstrează motorul Wavelet calibrat în șase straturi și adaugă un flux Beginner mai puternic, instrumente vizuale de control, procesare ROI, istoric navigabil și Procesare multiplă la rezoluție completă.

Aplicația nu face stacking, nu procesează fișiere video și nu generează detalii astronomice cu inteligență artificială. Imaginea sursă nu este suprascrisă de fluxul normal de lucru.

### Fișierele release-ului

- `StarSimCore-Setup-1.0.0-win-x64.exe` — installerul recomandat;
- `StarSimCore-1.0.0-win-x64-portable.zip` — versiunea portabilă;
- `SHA256SUMS.txt` — amprentele SHA-256 ale installerului și arhivei portabile;
- `StarSimCore-Setup-1.0.0-win-x64-README.md` — ghidul livrat lângă installer.

Descărcați build-uri oficiale numai din pagina GitHub Releases a repository-ului oficial sau din linkurile publicate pe [starsim.ro](https://starsim.ro/).

### Noutăți principale în 1.0.0

- **Procesare multiplă în două moduri:** fără imagine deschisă, selectați folderul, editați prima imagine și apăsați **Aplică pe tot batch-ul**; cu o referință deja editată, selectarea folderului pornește automat procesarea.
- Batch-ul folosește un `PipelineSnapshot` imuabil, procesează secvențial la rezoluție completă și scrie rezultatele în `StarSim_Batch` sub forma `<nume>_batch_0001`.
- **ROI:** activați ROI, selectați planeta, lucrați rapid pe crop-ul nativ float32 și folosiți **Aplică pe toată imaginea** pentru randarea finală completă.
- **Clipping Warning:** pixelii procesați care ating albul de afișare sunt marcați cu roșu numai în preview; overlay-ul nu intră în export.
- **Istoric vizual:** reviziile imuabile ale pipeline-ului pot fi inspectate și selectate direct, fără apăsări repetate pe Undo.
- **Scurtături complete:** History, Clipping, ROI, aplicare pe imaginea completă, Undo/Redo și fluxurile principale sunt documentate în fereastra Ajutor/Despre.
- **Beginner îmbunătățit:** profilele planetare oferă mai mult detaliu fin. Contribuția nominală L1 crește exact de la 47 la 57, iar L2–L6 sunt scalate proporțional față de neutru.
- **Module revizuite:** Multi-scale Sharpen, Deringing/Halo Protection, Noise Reduction, Local Detail și Advanced Tone au formule și comportamente corectate/documentate.
- Exportul normal și Batch folosesc același `ResourceGovernor` pentru admiterea controlată a memoriei și procesorului.
- Interfață și ajutor complet în română și engleză, meniu contextual pe imagine, ferestre separate pentru module, iconiță Windows și informații de susținere pentru Asociația Star Sim.
- Plugin Manager, panouri Expert generate automat, plugin demonstrativ RGB-to-B&W / Invert & Tint și SDK C++ complet.

### Motorul Wavelet

Motorul Wavelet calibrat nu a fost modificat în această etapă. Cele șase slidere Classic controlează direct contribuția benzilor L1–L6. Denoise, Sharpen și Threshold rămân controale Advanced independente. Diagnosticul Expert poate exporta sursa, reconstrucția și benzile individuale.

### Instalare

1. Descărcați installerul și `SHA256SUMS.txt` din același GitHub Release.
2. Verificați amprenta SHA-256 dacă fișierul a fost obținut din altă locație.
3. Rulați `StarSimCore-Setup-1.0.0-win-x64.exe`.
4. Selectați română sau engleză și, opțional, scurtătura pe desktop.

### Limitări și siguranță

- nu există actualizare automată;
- performanța depinde de dimensiunea imaginii, CPU și memoria disponibilă;
- procesoarele native sunt CPU-first; accelerarea SIMD/GPU rămâne o direcție viitoare;
- pluginurile native rulează în proces și nu sunt izolate — instalați numai DLL-uri de încredere;
- build-urile modificate, fork-urile, installer-ele reîmpachetate și pluginurile terțe nu sunt build-uri oficiale StarSim Core și sunt responsabilitatea distribuitorilor lor.

## English

### About this release

StarSim Core `1.0.0` is the first stable release of the application for non-destructive mathematical post-processing of already-stacked astronomical images. It preserves the calibrated six-layer Wavelet engine and adds a stronger Beginner workflow, visual safety tools, ROI processing, navigable history, and full-resolution Batch Processing.

The application does not stack frames, process video files, or generate astronomical detail using artificial intelligence. The normal workflow never overwrites the source image.

### Release files

- `StarSimCore-Setup-1.0.0-win-x64.exe` — recommended installer;
- `StarSimCore-1.0.0-win-x64-portable.zip` — portable package;
- `SHA256SUMS.txt` — SHA-256 checksums for the installer and portable archive;
- `StarSimCore-Setup-1.0.0-win-x64-README.md` — guide distributed beside the installer.

Download official builds only from the official repository's GitHub Releases page or links published on [starsim.ro](https://starsim.ro/).

### Main additions in 1.0.0

- **Two-mode Batch Processing:** with no image open, select a folder, edit the first image and choose **Apply to Entire Batch**; with an already edited reference, selecting the folder starts processing automatically.
- Batch uses an immutable `PipelineSnapshot`, processes sequentially at full resolution, and writes results to `StarSim_Batch` as `<name>_batch_0001`.
- **ROI:** enable ROI, select the planet, work quickly on the native float32 crop, then use **Apply to Full Image** for the complete final render.
- **Clipping Warning:** processed pixels reaching display white are marked in red in the preview only; the overlay is never exported.
- **Visual history:** immutable pipeline revisions can be inspected and selected directly instead of repeatedly pressing Undo.
- **Complete shortcuts:** History, Clipping, ROI, full-image application, Undo/Redo, and the primary workflows are documented in Help/About.
- **Improved Beginner workflow:** planetary profiles provide additional fine-detail headroom. The nominal L1 contribution increases exactly from 47 to 57, while L2–L6 are scaled proportionally above neutral.
- **Revised processors:** Multi-scale Sharpen, Deringing/Halo Protection, Noise Reduction, Local Detail, and Advanced Tone have corrected and documented behavior.
- Normal export and Batch share the same `ResourceGovernor` for controlled CPU and memory admission.
- Complete Romanian and English UI/help, image context menu, separate movable module windows, Windows application icon, and Star Sim Association support information.
- Plugin Manager, automatically generated Expert panels, RGB-to-B&W / Invert & Tint demonstration plugin, and complete C++ SDK.

### Wavelet engine

The calibrated Wavelet engine was not changed in this stage. The six Classic sliders directly control L1–L6 band contribution. Denoise, Sharpen, and Threshold remain independent Advanced controls. Expert diagnostics can export the source, reconstruction, and individual bands.

### Compatibility and upgrading

- Windows 11 x64 — recommended and supported;
- Windows 10 22H2 x64 — best-effort compatibility;
- Windows ARM64, Windows 7, and Windows 8.1 — unsupported;
- the package is self-contained for .NET and includes Microsoft Visual C++ Runtime x64 installation;
- the unchanged installer `AppId` allows an in-place upgrade from `0.9.0-beta.1` to `1.0.0`;
- existing `.starsim` projects retain their saved canonical parameters and are not silently upgraded;
- reapply a Beginner preset to opt into the stronger mapping;
- settings, personal presets, and plugins in `%AppData%\StarSimCore` remain in place during upgrade/uninstall.

### Installation

1. Download the installer and `SHA256SUMS.txt` from the same GitHub Release.
2. Verify the SHA-256 checksum if the file came from another location.
3. Run `StarSimCore-Setup-1.0.0-win-x64.exe`.
4. Select Romanian or English and optionally create a desktop shortcut.
5. Complete installation and launch StarSim Core.

Microsoft Defender SmartScreen may warn about an unsigned installer until the distribution gains reputation. Always verify the source and SHA-256 checksum.

### Limitations and safety

- there is no automatic updater;
- performance depends on image dimensions, CPU, and available memory;
- native processors are CPU-first; SIMD/GPU acceleration remains future work;
- native plugins execute in-process and are not sandboxed — install only trusted DLLs;
- modified builds, forks, repackaged installers, and third-party plugins are not official StarSim Core builds and remain the responsibility of their distributors.
